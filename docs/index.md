# NLP Learning Hub

**Natural Language Processing dengan Python**: belajar dari nol sampai mampu
membangun, mengevaluasi, dan men-*deploy* model klasifikasi teks.

Seluruh materi memakai satu studi kasus utama: **klasifikasi postingan Twitter/X
untuk mengidentifikasi pesan kebencanaan, yaitu *Emergency* vs *Non-Emergency***.
Anda akan mengikuti satu proyek yang tumbuh dari baseline sederhana menjadi
sistem NLP yang lebih lengkap.

## Kurikulum

| Level | Topik | Hasil belajar utama |
|---|---|---|
| [0](level-0-orientasi/index.md) | Orientasi NLP | Memahami masalah, istilah dasar, dan menyiapkan lingkungan kerja |
| [1](level-1-python/index.md) | Python untuk NLP | Mengolah teks, file, CSV/JSON, NumPy, pandas, dan regex |
| [2](level-2-fondasi-teks/index.md) | Fondasi teks dan preprocessing | Membangun pipeline preprocessing yang dapat diuji |
| [3](level-3-representasi-teks/index.md) | Representasi fitur | Mengubah teks menjadi BoW dan TF-IDF tanpa kebocoran data |
| [4](level-4-machine-learning/index.md) | Machine learning klasik | Melatih dan membandingkan model secara adil |
| [5](level-5-evaluasi/index.md) | Evaluasi dan analisis kesalahan | Memilih metrik yang tepat dan menulis laporan eksperimen |
| [6](level-6-deep-learning/index.md) | Deep learning | Memahami embedding, RNN, Transformer, dan fine-tuning |
| [7](level-7-advanced-nlp/index.md) | Advanced NLP dan deployment | Membuat API, pengujian, monitoring, dan dokumentasi model |

## Capaian pembelajaran

Setelah menyelesaikan kurikulum, Anda mampu:

- [ ] Menjelaskan perbedaan AI, machine learning, deep learning, dan NLP.
- [ ] Menulis kode Python untuk membaca, membersihkan, dan menganalisis teks.
- [ ] Merancang pipeline preprocessing dan menjustifikasi setiap langkahnya secara empiris.
- [ ] Melatih dan membandingkan model klasifikasi teks tanpa kebocoran data.
- [ ] Memilih metrik evaluasi sesuai risiko masalah dan menganalisis kesalahan model.
- [ ] Menjelaskan arsitektur Transformer dan alur fine-tuning model berbahasa Indonesia.
- [ ] Menyajikan model lewat API yang tervalidasi dan mendokumentasikan batasannya.

## Prasyarat

- Komputer dengan Python 3.10 atau lebih baru.
- Kemampuan dasar mengetik di terminal dan membuat file teks.
- **Tidak** diperlukan pengetahuan NLP, machine learning, atau pemrograman Python yang mendalam.

!!! warning "Catatan penting tentang studi kasus"
    Model klasifikasi pesan darurat dalam materi ini adalah **alat belajar**.
    Ia bukan sistem penentu keadaan darurat otomatis dan tidak menggantikan
    verifikasi oleh manusia. Dataset yang disertakan bersifat **sintetis** dan
    ilustratif, sehingga skor yang dihasilkannya tidak boleh dianggap sebagai
    kinerja di dunia nyata.

# Level 0: Orientasi NLP

Level ini tidak menuntut kemampuan pemrograman. Tujuannya membangun peta
mental: apa itu NLP, apa masalah yang akan kita selesaikan, dan bagaimana
menyiapkan lingkungan kerja.

**Estimasi waktu:** 6–8 jam, termasuk instalasi dan mini proyek.

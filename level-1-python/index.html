    Level 1: Fondasi Python untuk NLP¶

    Level ini mengajarkan bagian Python yang paling sering dipakai dalam pemrosesan teks, semuanya dengan contoh laporan kebencanaan. Jika Anda sudah mahir Python, kerjakan latihan di setiap halaman sebagai pemeriksaan cepat.

    Estimasi waktu: 20–28 jam, termasuk latihan. Prasyarat: Level 0, terutama Persiapan Python.

    Daftar materi¶

    # Materi Tingkat Skrip contoh
    1 Variabel dan tipe data Pemula 01_variabel_tipe_data.py
    2 String dan operasi teks Pemula 02_string_operasi_teks.py
    3 Indexing dan slicing Pemula 03_indexing_slicing.py
    4 List, tuple, set, dictionary Pemula–menengah 04_koleksi.py

    Capaian¶

    • Menulis dan menjalankan skrip Python yang memakai variabel, kondisional, perulangan, dan function.
    • Memilih wadah yang tepat (list, tuple, set, dictionary) dan menghitung frekuensi kata.
    • Membaca dan menulis berkas teks, CSV, dan JSON dengan encoding UTF-8.
    • Memakai NumPy dan pandas untuk memeriksa dan membersihkan tabel kecil.
    • Menulis pola regex sederhana dan menjelaskan jebakannya.
    • Membaca traceback, menangani galat, dan menulis uji sederhana.

    Cara menjalankan contoh¶

    Dari akar repository, dengan .venv aktif:

    python -X utf8 examples/level-1-python/01_variabel_tipe_data.py

    -X utf8 menghindari UnicodeEncodeError pada konsol Windows lama saat mencetak emoji. Halaman 12–14 membutuhkan numpy dan pandas; halaman 16 membutuhkan pytest (pip install -r requirements-ml.txt). Dataset kecil sintetis ada di examples/level-1-python/data/laporan_contoh.csv.

    Pola halaman dan status pengujian

    Setiap halaman memecah skrip menjadi bagian-bagian bernama (--8<-- "file.py:bagian"), dan seluruh blok "Output nyata" dicocokkan otomatis dengan hasil eksekusi skrip (examples/check_page_outputs.py). Lihat Audit dan Verifikasi.

    Checkpoint praktis¶

    Sebelum lanjut ke Level 2, pastikan Anda dapat, tanpa melihat catatan:

    1. Menghitung frekuensi kata dari sebuah kalimat dengan dictionary.
    2. Menjelaskan mengapa 0.1 + 0.2 == 0.3 salah dan mengapa string tidak dapat diubah.
    3. Membaca laporan_contoh.csv dengan pandas dan menghitung jumlah teks kosong dan duplikat.
    4. Menulis fungsi kecil beserta dua assert untuk kasus normal dan kasus tepi.

    Materi selanjutnya¶

    Mulai dari Variabel dan Tipe Data. Setelah Level 1, lanjut ke Level 2.
